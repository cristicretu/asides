Talk through bugs while you test.

Press ⌃⌥Space and say what's wrong. asides transcribes it on your Mac and appends it to a Markdown note in your repo, screenshots inline, ready for a colleague or a coding agent.

Seconds later, it's in the note as #5. Keep testing.

Local and free

Whisper runs on your Mac's GPU. No account, no API key, and no audio leaves your Mac.

Verbatim

What you said, as Whisper heard it. No rewriting, no summaries.

Screenshots in place

Copy a screenshot while you talk, and it lands next to the sentence you were saying.

Any language

Detected for each recording. List the languages you speak, and it picks between those.

Context included

Each new note records the branch, commit and uncommitted changes, plus your browser and display.

Ready for agents

Plain Markdown in your repo. asides path prints the latest note for your agent.

Install

  1. Install it with Homebrew. It's signed and notarized by Apple.

    brew tap mihaicristianfarcas/asides \
  https://github.com/mihaicristianfarcas/asides
brew install --cask mihaicristianfarcas/asides/asides

    Or download it, move it to Applications, and link the command inside it into a folder on your PATH:

    mkdir -p ~/.local/bin
ln -s /Applications/Asides.app/Contents/Helpers/asides \
  ~/.local/bin/asides

  2. Run it in your project. The first launch asks for the microphone and downloads the speech model (574 MB).

    cd ~/code/shop && asides
⌃⌥Space
Record, then stop. Or hold while you talk.
⌃⌥N
Record into a new note.
⌃⌥V
Attach the image on the clipboard.
Esc
Cancel. Nothing is written.

Or build it from source with make install.
